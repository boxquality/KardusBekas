BOXQUALITY — WEBSITE 3D CINEMATIC
=================================

CARA PAKAI
1. Ekstrak ZIP ini.
2. Upload semua isi folder BOXQUALITY ke repository GitHub Pages.
3. Pastikan index.html berada di root repository (bukan di dalam folder BOXQUALITY).
4. Jangan pisahkan folder css, js, images, dan assets dari index.html.
5. Buka website menggunakan koneksi internet karena Three.js, Google Fonts, dan GSAP/ekosistem CDN dimuat dari internet.

STRUKTUR
- index.html: struktur halaman.
- css/: semua file desain dipisah.
- js/: fungsi utama, loading, animasi, scroll, dan scene Three.js.
- images/: tempat foto produk/logo milikmu.
- assets/3d/: tempat model 3D tambahan (.glb/.gltf).
- assets/video/: tempat video.
- assets/audio/: tempat audio.

CATATAN 3D
Scene kardus utama dibuat secara real-time dengan Three.js (geometri 3D), bukan gambar atau video. GSAP sudah disediakan sebagai import map bila nanti ingin menambahkan animasi timeline lebih lanjut. Scene 3D memerlukan browser yang mendukung WebGL dan koneksi internet untuk memuat library CDN.
